## ⚙️ Installation & Run

### Prerequisites
- Flutter SDK (latest stable)
- Android Studio or VS Code
- Android Emulator or physical device
- Git

### Installation
```bash
git clone https://github.com/IrghimKurniawan/courtbooking.git
cd courtbooking
flutter pub get

### Running
flutter run

# Android
flutter run -d android

# Web (Chrome)
flutter run -d chrome
